## Exact encoder math

Common m0 = boxed background material minus saved background step times L-gradient at background. No TV in this cheap initializer; A25 cached certified TV initializer is an additional no-NN reference, not a free online operation. Observation layout [B,32,8] complex128; material [Re576,Im576] real MASS. BG derivative J is allowed only because chi_b is known. Cache geometry/material/background descriptors are validated; do not reinterpret a truth-state Jacobian as background.

At m0: L uses w=diag(h) eb, field=eb. R uses existing TASK_R32 Woodbury closure and its exact paired derivative/adjoint. Compute data-gradient g_L/R in A25 normalized objective. Base mbar=box(m0-step*g); N1,N3 use L, N2 R. Thus N1/N3 physical outputs are exactly equivalent while their OBSERVATION features differ. N2 changes only the explicit feedback physical model, with the same CNN/prior/loss/step count.

OM O: complex rank16 truncated SVD of known Db, wO=V16 diag(1/s16) U16* (measurement-yb). Materialized zO[n]=sum_s conj(eb[n,s])*wO[n,s]/sum_s abs(eb[n,s])^2. Dark denominator fails using old relative pole guard; do not insert a hidden ridge. BP alternative is the unprojected ordinary background-adjoint increment in physical material coordinates. O and BP use the same measurement/background; no target access.

Channels ordered: base_delta_real, base_delta_imag, O_or_BP_real, O_or_BP_imag, gradient_mass_real, gradient_mass_imag, source_mean_field_power, source_mean_w_power, background_real, background_imag, confidence_diag_real, confidence_diag_imag. For N1/N2 O is identical; for N3 substitute ordinary BP image. Source-shared means, no per-source arbitrary material maps. Core/fixed reference definitions unchanged. Forward residual guard <=1e-10. No fallback.

Confidence: SVD of cached REAL MASS background J, with sigma>0 covariance sigma^2/2 per real datum; scalar whitening scales all singulars and relative cut equally. C=V diag(s^2/(s^2+(.05*smax)^2)) V^T. Hence same C per background under this relative-cut rule; explain it is numerical confidence, not calibrated statistical recoverability. Noiseless uses background-scale normalized operator, not zero-sigma whitening. Save spectrum and full C/weak operator for diagnostics. Main CNN output unrestricted inside full grid box, no weak-space projection. Beta = ||data_R(m0)-data_L(m0)||/(sigma sqrt(q*s)); sigma0 is a separate NOISE_FREE group, represented by NaN in arrays with explicit group, not a fake floor.
