# A26 evaluation interface audit

Status: READ_ONLY_STATIC_INTERFACE_AUDIT. Source was read on 2026-10-09. No implementation file was changed. No numerical command, remote command, dataset/locked payload read, new label, or scientific gate judgment was performed.

Scope: `src/a26/evaluation.py`; inherited `src/a24/physics.py`, `src/a24/contracts.py`, `src/a24/relative_feedback.py`; reused `src/a25/torch_physics.py`; the encoder and checkpoint interfaces needed to verify caller behavior. The observations below concern code paths and interfaces, not numerical evidence that the study supports a claim.

## Normalization and timer boundaries that match the inherited contract

1. `CachedFullPhysics` restores G/S/incident and the dimensions/volume used by inherited `full_state`, `factor_matrix`, `solve_factor`, `green`, `observe`, and `material_pullback`. Those called inherited operations do not require omitted constructor-only geometry fields. The full solve remains `L=I-diag(chi)G`, RHS `diag(chi)incident`, and `field=incident+Gcurrent` (`evaluation.py:42-62`; `physics.py:186-220`).
2. Full JVP converts a real mass direction with inherited `mass_unpack`, injects `dchi*field`, solves the saved full factor, then observes/packs. Full VJP solves the conjugate-transposed full factor against `S*load` and calls inherited `material_pullback`, which divides by sqrt(volume). This matches the real-mass direction/output convention used by TorchRelativeModel (`evaluation.py:54-62`; `torch_physics.py:539-569`; `contracts.py:115-123`). No extra volume factor or sign discrepancy was found by source inspection.
3. Full and R material gradients both load the complex data adjoint with `(predicted_data-observation)/||yb||²`. This is the gradient of the inherited `.5*||residual||²/||yb||²` objective; no factor of two is missing (`evaluation.py:96-98`; `torch_physics.py:571-573`). The raw JVP/VJP comparison correctly leaves that objective normalization out of both arms.
4. Data residual whitening uses `sqrt(2)*||residual||/sigma`, consistent with sigma²/2 variance per real datum (`evaluation.py:164`). Noise-free rows leave that metric undefined.
5. The reported total online latency starts before the raw NumPy observation enters `encode`, includes input device transfer, the physical encoder, feature normalization, CNN, box, mass-to-chi conversion, and image transfer back to CPU (`evaluation.py:215-222`; `training.py:851-855`). The independent full forward audit starts after the image timer ends and has separate time/counters (`evaluation.py:223-230`). The cache-only prediction path is used for quality evaluation and is not presented as total inference latency.
6. Checkpoint loading calls `model.eval()`, and the timing caller uses `torch.no_grad()` (`training.py:886`; `evaluation.py:216,239`). The checkpoint wrapper applies the shared normalizer and shared material RMS before the decoder. The explicit 576/24 conversion is correct for the frozen 24x24, volume1/576 contract enforced by the dataset/checkpoint interfaces; it is not a general-grid API.

## Concrete findings

| Priority | Source | Defect and consequence | Minimal repair within the frozen implementation |
|---|---|---|---|
| P2 | `evaluation.py:205-226` | Rows are labeled `RESIDENT_WARM` without an excluded warm-up. New encoders have `observable_ready=False`; the first N1/N2 encode for each background performs the lazy Db SVD inside the reported encoder interval. The first CNN call is also un-warmed. Median aggregation does not make every row a warm measurement. | Perform charged raw-observation warm-up calls for each method/background before collecting warm rows, and record warm-up cost separately. Retain N1/N3's prohibition on R calls. Keep fresh encoder/checkpoint measurements separate. |
| P2 | `evaluation.py:96,115-121` | `gradient_diagnostic` calls `enc.models['R']` directly and bypasses the encoder's explicit `||A_R w-h eb||/||h eb||` residual check. TorchRelativeModel guards the core/solve finiteness, but does not enforce that forward residual. The diagnostic record therefore has full backward residual and R core margins but no guarded R forward residual. | Call the existing matching residual guard after the R forward and store its result. Keep failure explicit and do not replace a failed R state with L. |
| P2 | `evaluation.py:90-122,180-185`; frozen protocol line13 | Typical-state diagnostics compute R and full F only. The outer prediction method label N1/N2/N3 selects which predicted image is examined; it does not cause an L derivative/adjoint/gradient evaluation. The requested L/R/F diagnostic interface remains incomplete. | Add an explicit physical arm dimension or parallel L fields at the same estimated chi, observation, and probe directions. This is an offline diagnostic; do not add R work to N1/N3 online timing. |
| P1 | `evaluation.py:165-166,185-186` | Broad `except Exception` also catches `BudgetExceeded`, including hard resource-limit and ownership/lock failures raised by the shared book inside physics spans. These are recorded as numerical rows instead of immediately propagating the stop. If the last diagnostic raises this way, execution can proceed to a `COMPLETE_EXPOSED_DEVELOPMENT_EVALUATION` summary without a later external `book.check()` stopping it. | Preserve the failure receipt and re-raise budget/ownership failures before the numerical-error handler. Only numerical/ordinary per-case exceptions should become failed diagnostic rows. |
| P2 | `evaluation.py:108,120-121` | `error()` deliberately returns None when the full reference norm is zero, but the boolean expression directly evaluates `error(ar,af)<=.05` and `error(jr,jf)<=.05`. An undefined adjoint/JVP ratio produces TypeError and loses already-computed diagnostic values when the outer handler reduces the record to FAILED. | Compute the ratios once, retain them as nullable fields, and check `is not None` before comparisons. Mark zero-reference cases explicitly; do not insert a floor to turn an undefined ratio into a passing value. |

Additional normalization note: `evaluation.py:114` normalizes the reduced adjoint dot defect with an unreported `1e-30` floor. An exactly zero pair of probe inner products yields a reported relative defect of zero even though its relative normalization is undefined. Saving the absolute dot defect plus a nullable relative defect/zero-scale status would make this diagnostic unambiguous. This note does not assert that such a pair occurs in the frozen data.
